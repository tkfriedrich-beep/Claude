# Skill: SEO Tools

Playbook for SEO analysis and optimization tasks.

## Site Audit

1. Fetch the target page with WebFetch
2. Check for:
   - Title tag (50-60 chars, includes target keyword)
   - Meta description (150-160 chars, compelling CTA)
   - H1 tag (one per page, includes keyword)
   - Header hierarchy (H1 > H2 > H3, logical structure)
   - Image alt text (descriptive, includes keywords where natural)
   - Internal linking (relevant, sufficient quantity)
   - Page load considerations (image sizes, scripts)

## Keyword Research

1. Start with seed keywords from the user
2. Use WebSearch to find related terms and questions
3. Analyze competitor pages for keyword usage
4. Organize into clusters by intent:
   - **Informational**: "how to", "what is", "guide"
   - **Commercial**: "best", "review", "compare"
   - **Transactional**: "buy", "pricing", "sign up"

## Content Optimization

1. Identify target keyword and intent
2. Analyze top-ranking pages for the keyword
3. Recommend:
   - Optimal word count (based on competitors)
   - Subtopics to cover
   - Questions to answer
   - Internal/external link opportunities
