Article Text Copier

Extract article text without photos

How it works

  1. Open the article in Safari
  2. Select All (tap & hold, then "Select All")
  3. Copy the content
  4. Come back here and paste into the box below
  5. Tap "Extract Text" to strip images and formatting

One-tap extraction

Add a bookmarklet to Safari for one-tap article text extraction while reading.

Setup (one time)

  1. Tap the button below to copy the bookmarklet code
  2. In Safari, bookmark any page
  3. Edit the bookmark: rename it to "Get Text"
  4. Replace the URL with the copied code
  5. Save the bookmark

Usage

  1. Open any article (Substack, Medium, etc.)
  2. Tap the address bar and start typing "Get Text"
  3. Select the bookmarklet
  4. Article text is copied to your clipboard!

A banner will confirm when text is copied.
