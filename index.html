  4. Come back here and paste into the box below
  5. Tap "Extract Text" to strip images and formatting

iOS Shortcut Power user

Create an iOS Shortcut that extracts article text directly from the Substack share sheet — no switching apps needed.

Create the Shortcut

Open the Shortcuts app and create a new shortcut with these actions in order:

  1. Receive input from Share Sheet Accept: URLs If there is no input: Ask For → URL
  2. Get Contents of URL URL: Shortcut Input
  3. Make Rich Text from HTML Input: Contents of URL
  4. Get Text from Input Input: Rich Text from HTML This strips all images and formatting
  5. Copy to Clipboard Input: Text
  6. Show Notification Title: "Article Copied!"

Setup

  1. Name the shortcut "Get Article Text"
  2. Tap the ⓘ at the top → enable "Show in Share Sheet"
  3. Under Share Sheet Types, select only URLs

Usage

  1. Open any article in the Substack app
  2. Tap the Share button
  3. Tap "Get Article Text" in the share sheet
  4. You'll get a notification — the text is on your clipboard!

Works with Substack, Medium, WordPress, and any web article.

Safari Bookmarklet Safari only

One-tap text extraction while browsing in Safari. Does not work in the Substack app — use the From Link or Shortcut tab instead.

Setup (one time)

  1. Tap the button below to copy the bookmarklet code
  2. In Safari, bookmark any page
  3. Edit the bookmark: rename it to "Get Text"
  4. Replace the URL with the copied code
  5. Save the bookmark

Usage

  1. Open any article in Safari
  2. Tap the address bar and type "Get Text"
  3. Select the bookmarklet
  4. Article text is copied to your clipboard

A green banner confirms when text is copied.
